# Contributing

OIO Local accepts focused issues and pull requests that preserve its approved
outcome-first behavior, local operating boundary, bilingual interface, and safe
installation and uninstall paths.

Before submitting a change:

```bash
npm ci
npm test
```

Changes to bundled third-party skills must update the compatibility manifest,
source identity, content hashes, modification record, and license evidence.
Do not silently replace or edit attributed upstream material.

Do not commit secrets, environment files, runtime databases, dependency
folders, caches, generated output, private review receipts, or OIO Business
source.
