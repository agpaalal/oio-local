# Security policy

Do not include secrets in issues, discussions, logs, review artifacts, or test
fixtures. OIO Local does not create project `.env`, `.dev.vars`, or
`.oio.local.env` files. Use Doppler for secret-bearing work.

Report a suspected vulnerability privately through GitHub's vulnerability
reporting interface for this repository. Include the affected version, the
smallest reproduction, expected impact, and any known safe workaround. Do not
open a public issue for an unpatched vulnerability.

Only the current release is supported during V0.
